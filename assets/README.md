# Assets

## `brand/`

Official Crewmoor logo files, copied unchanged from the *Crewmoor Logo Production v1* kit.

| File | Use |
| --- | --- |
| `crewmoor-logo-color.svg` | Horizontal logo for light backgrounds |
| `crewmoor-logo-white.svg` | Horizontal logo for dark backgrounds |

Do not redraw, recolour, distort or add effects to these files. If a different format or variant is needed, take it from the original kit.
