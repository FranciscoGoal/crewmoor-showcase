# Brand assets

No generated or recreated Crewmoor logo is included in this package.

To keep the brand accurate, add **only your original approved logo file**, without redrawing, changing colors, distorting or re-styling it. For a GitHub README, use an existing original PNG/SVG asset you own and then add this line above the main title in `README.md`:

```html
<img src="assets/crewmoor-logo.svg" alt="Crewmoor" width="220" />
```

Use the actual uploaded filename and avoid including unused or proprietary design materials.

For the repository social preview, upload a professionally prepared image containing the unaltered original logo in GitHub Settings → General → Social preview.
